# Unlocking Malleability in HPC Applications

A hands-on tutorial on transforming rigid MPI applications into malleable ones using **FlexMPI**.

---

## Tutorial Program

### Part 1 — Introduction and Content Access (1 hour)

| Segment | Duration |
|---|---|
| Introduction to HPC and dynamic systems | 30 min |
| FlexMPI architecture and programming model | 20 min |
| Environment setup and documentation access | 10 min |

### Part 2 — Preparing the Setup (1 hour)

| Segment | Duration |
|---|---|
| Docker environment overview | 15 min |
| Building the Docker image | 30 min |
| User interface walkthrough | 15 min |

### Part 3 — Demo Execution (1 hour)

| Segment | Duration |
|---|---|
| From pure MPI to FlexMPI | 30 min |
| Live demo and execution walkthrough | 30 min |
| (Optional) Malleable execution video | 5–10 min |

---

## What You Will Learn

- The fundamentals of malleability in HPC systems
- How FlexMPI enables dynamic resource management
- How to convert a standard MPI application into a malleable one
- How to set up and use a Docker-based development environment for rapid prototyping

---

## Prerequisites

- Basic knowledge of MPI programming
- Docker installed on your machine
- Familiarity with C/C++ and Linux command line
